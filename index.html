GOTOTO Music Tools

GOTOTO Music Tools is an internal content management tool for the GOTOTO music project. It helps manage short-form original music videos for TikTok using TikTok Login Kit and the TikTok Content Posting API.

Terms of Service | Privacy Policy

What this app does

  • Sign in with TikTok using OAuth.
  • Confirm the authenticated user's basic TikTok profile using user.info.basic.
  • Select a local MP4 video file.
  • Upload the MP4 to TikTok as a draft using video.upload.
  • Check the upload status and confirm SEND_TO_USER_INBOX.

Current review scope

  • Login Kit
  • Content Posting API
  • user.info.basic
  • video.upload

Direct publishing with video.publish is not enabled until TikTok approves Direct Post.

Demo flow

  1. Open GOTOTO Scheduler.
  2. Click “Sign in with TikTok”.
  3. Complete TikTok OAuth authorization.
  4. Return to the registered callback URL.
  5. Check user.info.basic.
  6. Select a local MP4 file.
  7. Upload the MP4 as a TikTok draft.
  8. Fetch status and confirm SEND_TO_USER_INBOX.
